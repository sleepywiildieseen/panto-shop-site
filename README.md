# Panto — Интернет-магазин минималистичной мебели

Полноценный Fullstack-проект: каталог мебели, корзина, регистрация/авторизация (JWT), оформление заказов и управление товарами через админку Django.

## 🛠 Стек технологий
*   **Frontend:** React 18, Vite, React Router, чистый CSS (без сторонних UI-библиотек).
*   **Backend:** Django 5, Django REST Framework, SimpleJWT.
*   **База данных:** PostgreSQL (через `psycopg`).
*   **Дизайн:** Figma.

## 📄 Страницы приложения
1.  `Главная (Home)` — hero-секция с поиском, блок "Best Selling", блок преимуществ.
2.  `Каталог (Catalog)` — сетка товаров с фильтрацией по категориям, сортировкой по цене и поиском.
3.  `О нас (About)` — информация о компании, материалы, отзывы клиентов.
4.  `Корзина (Cart)` — управление количеством товаров, удаление, подсчёт итоговой суммы.
5.  `Оформление (Checkout)` — форма для ввода данных доставки и создание заказа.
6.  `Успех (Success)` — страница подтверждения оформления заказа.
7.  `Авторизация (Login/Register)` — вход и создание аккаунта.

## ⚙️ Функции, связанные с БД
1.  **Аутентификация и авторизация:** Регистрация пользователя (пароль хэшируется), вход по JWT-токену. Защищённые маршруты (корзина, оформление) доступны только авторизованным пользователям.
2.  **Корзина (CRUD):** Добавление товара, изменение количества, удаление. Данные хранятся в БД и привязаны к пользователю.
3.  **Оформление заказа:** Транзакционное создание записи в `orders` и `order_items`, списание остатков со склада (`stockQuantity`) и очистка корзины.

## 📱 Адаптив
Дизайн проверен на разрешениях: **375px, 960px, 1200px, 1920px, 2560px**. Реализован через CSS media queries и `clamp()` для плавного изменения размеров шрифта.
